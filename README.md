# Reviz

La toute première mise en ligne de **Reviz**, mon application qui transforme un cours en fiches de révision et en QCM grâce à l'IA.

Le code avait été déposé ici sous forme d'un fichier `reviz-app.zip`, supprimé ensuite. Le projet continue dans le dépôt **Reviz-app** (privé) :
- un front-end React ;
- un back-end Node.js et Express ;
- l'API OpenAI pour générer les fiches et les QCM ;
- Stripe pour l'abonnement Premium.
